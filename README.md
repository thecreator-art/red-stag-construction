# Red Stag Construction (redstagcc.com)

Static site built with Astro and Tailwind CSS, deployed on Vercel from `main`.

```bash
npm install
npm run dev       # local development
npm run build     # static build to dist/ plus image optimization
npm run preview   # serve the built site
```

See `AGENTS.md` for how pages, interactivity and the build pipeline fit together.
